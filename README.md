# Бот подписки на закрытый канал

Что делает:

- пускает в закрытый канал по заявке и одобряет её только тем, у кого есть действующий доступ;
- даёт пробный период (по умолчанию 3 дня, один раз на человека), потом убирает из канала;
- принимает оплату через ЮKassa по ссылке на страницу оплаты и продлевает доступ на 30 дней;
- за день до конца напоминает про оплату;
- принимает от учеников фото задач с подписью, пересылает в чат преподавателя и хранит для выгрузки.

Деньги идут напрямую на счёт ИП в ЮKassa. Встроенные платежи Telegram и Telegram Stars не используются.

## Настройка (один раз)

1. **Бот.** Создать у @BotFather, получить токен.
2. **Канал.** Сделать канал приватным. Добавить бота администратором с правами
   «Добавление подписчиков» и «Блокировка пользователей».
   Старые пригласительные ссылки канала отозвать, иначе по ним можно войти мимо бота.
3. **Чат для вопросов.** Создать приватную группу только для преподавателя, добавить туда бота.
4. **id чатов.** Написать `/chatid` в канале и в группе (в группе — от имени админа из `ADMIN_IDS`,
   поэтому сначала заполните `ADMIN_IDS` и запустите бота; id канала можно узнать сразу).
5. **ЮKassa.** В личном кабинете: Интеграция → Ключи API. Сначала взять ключи тестового магазина.
6. **Настройки.** `cp .env.example .env`, заполнить, `chmod 600 .env`.

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot check   # проверит токен, права в канале, чат вопросов и ключи ЮKassa
python -m bot         # запуск (long polling: домен и вебхук не нужны)
```

Постоянная работа — через systemd: `deploy/tg-sub-bot.service`
(пути в файле рассчитаны на `/opt/tg-sub-bot` и пользователя `tgbot`).

Сервер должен видеть оба адреса: `api.telegram.org` и `api.yookassa.ru`.
Если Telegram с сервера недоступен, задайте `PROXY_URL`.

## Проверка перед боевым запуском

С ключами тестового магазина пройти весь путь вторым аккаунтом:

1. `/start` → «3 дня бесплатно» → войти в канал по кнопке.
2. «Оплатить» → на странице ЮKassa тестовая карта `5555 5555 5555 4444`, любой срок и CVC.
3. Через несколько секунд бот должен написать «Оплата получена».
4. Прислать фото с подписью — оно должно появиться в чате преподавателя.
5. От админа: `/revoke <id>` — человека должно убрать из канала; `/export` — должен прийти архив.

После этого заменить ключи на боевые и перезапустить бота.

## Команды преподавателя

| Команда | Что делает |
|---|---|
| `/admin` | список команд |
| `/stats` | сколько людей с доступом, сколько оплат |
| `/users` | у кого сейчас доступ и до какого числа |
| `/export`, `/export 30`, `/export all` | архив вопросов: картинки и страница `index.html` с подписями |
| `/grant <id> <дней>` | выдать или продлить доступ вручную |
| `/revoke <id>` | закрыть доступ и убрать из канала |

## Что важно знать

- **Кто уже в канале.** Бот знает только тех, кто пришёл через него. Старых участников он не тронет
  и не сможет убрать за неуплату. Их нужно либо завести через `/grant`, либо попросить нажать `/start`.
- **Чеки.** `YOOKASSA_SEND_RECEIPT=1` включайте, только если в ЮKassa подключены «Чеки от ЮKassa»:
  тогда бот перед первой оплатой спросит e-mail для чека. Ставку НДС (`VAT_CODE`) сверьте с налоговым режимом ИП.
- **Автопродления нет.** Каждый месяц человек платит сам по напоминанию. Автоплатежи в ЮKassa
  подключаются отдельной заявкой — это следующий шаг, не часть MVP.
- **Возвраты** делаются в кабинете ЮKassa, после чего доступ закрывается через `/revoke`.
- **Данные.** В базе: id и имя в Telegram, e-mail для чека, тексты вопросов и идентификаторы файлов.
  Сами картинки лежат на серверах Telegram и скачиваются только при `/export`.
  База — файл `data/bot.sqlite3`, его достаточно копировать для резервной копии.

## Устройство

| Файл | Зона ответственности |
|---|---|
| `bot/db.py` | SQLite: пользователи, платежи, вопросы |
| `bot/yookassa.py` | клиент API ЮKassa |
| `bot/access.py` | сроки доступа, вход и исключение из канала, зачисление оплат |
| `bot/handlers/` | сценарии в Telegram: ученик, заявки в канал, вопросы, команды преподавателя |
| `bot/export.py` | архив вопросов |
| `bot/main.py` | запуск и фоновые проверки |

Тесты: `pip install -r requirements-dev.txt && pytest`.
